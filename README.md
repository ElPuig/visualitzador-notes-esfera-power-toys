# Visualitzador de Notes Esfera PowerToys

Eina web lleugera per visualitzar de forma gràfica les notes exportades des d'Esfera PowerToys, facilitant les tutories individuals i el seguiment acadèmic de l'alumnat.

## Característiques

- Importació d'arxius Excel exportats des d'Esfera PowerToys.
- Selecció ràpida d'alumnes mitjançant desplegable.
- Visualització compacta de tots els mòduls i resultats d'aprenentatge.
- Codificació visual per colors:
- Resum automàtic de:
  - Resultats d'aprenentatge aprovats
  - Resultats d'aprenentatge suspesos
  - Resultats d'aprenentatge pendents
  - Mòduls aprovats
  - Mòduls a recuperar
- Llistat automàtic de mòduls pendents de recuperació.
- Exportació de la fitxa individual a PDF.
- Funcionament completament local dins del navegador.

## Objectiu

Aquesta eina neix amb la voluntat de facilitar les entrevistes de tutoria i les sessions de retorn de qualificacions, oferint una visió clara, compacta i visual de la situació acadèmica de cada alumne.

Permet substituir la consulta directa de fulls de càlcul per una fitxa molt més llegible i orientada a la conversa amb l'alumnat.

També permet enviar a l'alumne una versió del bolletí de notes més clara i comprensible visualment.

## Funcionament

1. Exportar les notes des d'Esfera mitjançant Esfera PowerToys.
2. Obrir l'arxiu `visualitzador-notes-esfera-power-toys.html`.
3. Carregar l'arxiu Excel exportat.
4. Seleccionar un alumne al desplegable.
5. Consultar la seva situació acadèmica.
6. Opcionalment, generar un PDF de la fitxa.

## Requisits

- Navegador web modern.
- Arxiu Excel exportat des d'Esfera PowerToys.

No requereix instal·lació ni servidor.

## Casos d'ús

- Entrevistes individuals amb alumnat.
- Seguiment tutorial.
- Revisió de qualificacions finals.
- Preparació de sessions d'avaluació.
- Generació de fitxes resum en PDF.
